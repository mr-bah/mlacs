# MLACS — поиск скрытых автокорреляционных сдвигов во временных рядах

**MLACS** (Multi-Lag AutoCorrelation Shift detector) — онлайн-алгоритм, который обнаруживает
изменение автокорреляционной структуры ряда, когда среднее и дисперсия **не меняются**.

Идея: ряд режется на блоки длины `b`; в каждом блоке считается вектор выборочной ACF на лагах
`1..L`; его отклонение от опорного участка измеряется расстоянием Махаланобиса и накапливается
статистикой CUSUM; порог калибруется параметрическим бутстрэпом на заданную вероятность
ложной тревоги.

## Быстрый старт

```python
import numpy as np, mlacs as m

# ряд: AR(1) 0.5 -> AR(2) (0.3, 0.4); среднее, дисперсия и rho_1 одинаковы
segs = [m.Segment(phi=(0.5,), length=3010), m.Segment(phi=(0.3, 0.4), length=1990)]
y = m.simulate_piecewise_ar(segs, rng=np.random.default_rng(0))[0]

for e in m.detect_sequential(y, lags=3, block=50, n_ref=2000, alpha=0.05):
    if e["alarm"] >= 0:
        print("тревога:", e["alarm"], "оценка момента изменения:", e["change_est"])
```

Командная строка (CSV с числовым столбцом):

```bash
python -m mlacs data.csv --column value --lags 3 --block 50 --n-ref 2000
```

Интерактивное приложение:

```bash
streamlit run app.py
```

## Воспроизведение результатов работы

```bash
python -m experiments.run_all     # калибровка, сценарии А–Г, сила сдвига, лаги, блок, локализация, бутстрэп
python -m experiments.robust      # шум с тяжёлыми хвостами (t, 5 ст. св.)
python -m experiments.multi       # несколько точек изменения
python -m experiments.plots       # рисунки 2.1, 3.1–3.4 -> figures/ (дополнительные -> figures/extra/)
python -m experiments.app_figure  # рисунок Б.1
python -m pytest -q tests         # тесты
```

Все генераторы случайных чисел инициализированы фиксированными значениями — результаты
воспроизводятся точно. Готовые таблицы лежат в `results/`, рисунки — в `figures/`.

## Структура

| Путь | Назначение |
|---|---|
| `mlacs/generators.py` | Кусочно-стационарные AR-ряды с сохранением дисперсии, теоретическая ACF |
| `mlacs/features.py` | Блочные признаки: ACF, спектральные доли, среднее, дисперсия |
| `mlacs/detectors.py` | Блочный CUSUM; MLACS и детекторы для сравнения |
| `mlacs/calibration.py` | Калибровка порога: Монте-Карло и параметрический бутстрэп |
| `mlacs/online.py` | Последовательный режим (несколько изменений) |
| `mlacs/offline.py` | Офлайн-перебор точки изменения (среднее; среднее+дисперсия; AR) |
| `app.py` | Приложение Streamlit |
| `experiments/` | Эксперименты и рисунки |
| `results/` | Готовые таблицы результатов |
| `figures/` | Рисунки работы (имена совпадают с номерами в тексте) |
| `tests/` | Тесты pytest |

## Основной результат

Сдвиг AR(1) 0.5 → AR(2) (0.3; 0.4): среднее, дисперсия и ρ₁ не меняются. Все детекторы
откалиброваны на 5 % ложных тревог (1000 рядов):

| Детектор | Обнаружено | Медианная задержка |
|---|---|---|
| MLACS, L = 2–3 | 94–95 % | 190 |
| ACF лага 1 | 76,5 % | 640 |
| Остатки AR(p) | 24,5 % | 940 |
